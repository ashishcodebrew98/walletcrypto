# walletcrypto

React (CDN) mobile-first wallet app prototype with end-to-end mock onboarding, KYC, and dashboard flows.

## Implemented flows

- Welcome + signup method selection
- Phone signup + OTP verification
- Email signup + password strength gating
- PIN create + confirm
- Biometric setup
- KYC introduction
- KYC Level 1 (basic profile)
- KYC Level 2 (advanced verification)
- KYC status screen
- Dashboard with tabs (Home, Wallets, Exchange, More)

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.
